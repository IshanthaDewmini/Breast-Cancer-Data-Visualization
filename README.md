#Breast Cancer Data Visualisation using Python

Introduction
This is a small research style data visualisation project to explore breast cancer tumor measurements using python. The goal of the project was to practice real working data sets and create a clear, research style figures that can be used to communicate patterns in the data. The dataset contains 569 tumor samples with measurements describing characteristics of cell nuclei, together with a diagnosis label of benign or malignant.

Objectives
1. Explore the structure of a biomedical dataset using python
2. Compare tumore differences between benign and malignant samples
3. reate publication style figures suitable for scientific data presentation.
4. Understanding relationship between selected tumor characteristics

Tools and Libraries
VS Code — Development environment 
Python - Programming language
Matplotlib - Data visualisation
scikit-learn - Dataset obtaining using built-in load_breast_cancer()
This project uses the Breast Cancer Wisconsin dataset available through scikit-learn to explore measurements associated with breast tumor samples.

Conclusion
The obtained graphs demonstrate several patterns within the dataset. The dataset contains both benign and malignant tumor samples. Mean radius measurements show different distributions between the two diagnosis groups. Several tumor measurements show correlations with one another, reflecting relationships between different measurements of cell nuclei.
